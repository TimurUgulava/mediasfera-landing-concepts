# Медиасфера — концепции посадочной страницы

Пять визуальных концепций первого экрана и полной посадочной страницы агентства **Медиасфера** (создание контента: Яндекс ПромоСтраницы, Дзен, СМИ, корпоративные блоги).

Принцип: **идея диктует контент** — у каждой концепции свой заголовок, своя композиция и свой тон.

## Концепции

| № | Концепция | Идея |
|---|-----------|------|
| 1 | [Редакция-издание](c1-redakciya.html) | вы нанимаете не копирайтера, а редакцию с именем |
| 2 | [Эта страница — наша работа](c2-demonstraciya.html) | не верьте словам — читайте пример |
| 3 | [Коты, которые растят CTR](c3-koty.html) | бренд с характером, контент с душой |
| 4 | [Посчитано до рубля](c4-dashboard.html) | контент — перформанс-канал с прозрачными цифрами |
| 5 | [Мемы](c5-memes.html) | контент, который понимает интернет |

Открыть всё с одной страницы: **[index.html](index.html)**.

Каждая концепция — полноценная страница из 7 экранов (hero → инсайт → кейсы → редакция → каналы → FAQ → форма). Чистый HTML/CSS, без сборки.
